## Remaining deployment checks

The user configured the frontend Supabase environment. No trusted Supabase project administrative access was supplied, so the new migration and Edge Function have not been deployed here. Existing projects must apply `202610220002_admin_staff_passwords.sql` and deploy `manage-staff` with `APP_URL` matching the browser origin. Account creation uses server-side auto-confirmation and needs no SMTP. No live staff password was created or changed during verification.

After deployment, verify administrator-created staff login without email confirmation, administrator password replacement, non-admin/cross-shop rejection with real JWTs, deactivated staff sessions, Edge Function CORS, and simultaneous checkout/payment requests. Embedded PostgreSQL serializes commands through one connection and is not a multi-connection load test. Edge Function source is linted; Deno runtime/deployment was not available here. Admin-only password management applies to this app and its staff endpoint; Supabase still supports account-owner password updates through its own Auth API, as documented in README.

Financial records must be exercised with test accounts before operating the shop. Expense receipt references are implemented; receipt-file storage is not. Invoice email sending and paid-invoice refunds/credit notes are not implemented. The app rejects voiding any invoice with payments and preserves its ledger.
